Home Server & Kalender Dashboard

Ein zentrales Dashboard zur Verwaltung von Server-Diensten, Container-Infrastruktur und persönlichen Terminen. Dieses Projekt kombiniert System-Monitoring mit einer übersichtlichen Kalender-Integration, optimiert für den Betrieb auf Single-Board-Computern.

Features

    Integrierter Kalender: Verwaltung und Visualisierung von Terminen, Aufgaben und Timelines.

    Server- & Netzwerk-Monitoring: Übersicht über Systemressourcen und Netzwerkinfrastruktur (z.B. Tailscale-Verbindungen).

    Container-Verwaltung: Schnittstellen-Integration zur Überwachung laufender Docker-Services (ähnlich Portainer).

    DNS & Ad-Blocking Stats: Einbindung von Netzwerk-Metriken (z.B. aus Pi-hole) direkt ins Dashboard.

    Responsive UI: Klar strukturiertes Frontend für Desktop und mobile Endgeräte.
